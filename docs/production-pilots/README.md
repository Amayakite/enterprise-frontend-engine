# 试点模块边界

当前没有待验收的生产试点。当前 API 与数据仍使用开发 Mock；成功回执不代表真实后端、持久化、权限或事务已联调。

## 当前定位

任务费用已完成前端闭环，仅作为局部能力参考，当前实现和边界见 [任务费用示例](../task-fee-example.md)。服务申请和会议申请已完成人工验收：前者覆盖密集参照和省市区联动，后者覆盖双明细、议程、定位、附件、整单校验和审批展示。

这两个模块只作为已验证的试点代码，不再作为后续开发依据。迁入新的真实业务模块并完成等价验证后，可连同对应 `/pilot` API 和 Mock 一并删除；删除前不得让菜单、路由或其他页面继续依赖它们。

## 新模块开发依据

新模块统一遵守 [业务模块开发规范](../business-module-standard.md) 和 [模块开发实操](../module-development-example.md)，结构均以 [客户管理](../customer-example.md) 为参照；无子表时精简对应装配，不再维护另一套试点开发规则。

删除试点前同时检查 API、菜单、隐藏路由、专属权限和文档引用；被其他模块使用的公共组件与工具不能一起删除。本说明不表示已经执行删除。

后续新试点优先选择能验证当前公共字段、跨单据选择或审批边界的真实模块；真实后端可用后仍须补充 URL、权限、数据范围、版本、事务、部分失败、取消和幂等联调结论。
